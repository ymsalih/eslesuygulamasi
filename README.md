- [Proje Analizi](docs/ANALIZ.md): KVKK ve 5651, mimari, takma ad, filtre, bildirim ayrıntıları
- [Yasal Uyum Kontrol Listesi](docs/YASAL_KONTROL_LISTESI.md): KVKK, 5651, süreçler ve avukata sorulacak sorular
